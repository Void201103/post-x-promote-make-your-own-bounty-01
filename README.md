Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty ($250 in USDC, top 50 paid): a validator for the X post link (`POST.json`) and the exact post text (`POST_TEXT.md`). The post quotes make.fun's make-your-own-bounty post on X, carries a photo, the play code, and the sponsor link — the house ranks posts by replies + reposts + quotes.

## Run it

```sh
node main.ts
```

Reads `POST.json` and `POST_TEXT.md`, prints one line per check, writes `report.json` to the output directory (`MAKEFUN_OUTPUT_DIR`, or `./output`). Exits 0 only when every check passes.
